# DEC-0001 — Only two hues, red and teal

| Field | Value |
|---|---|
| State | superseded by [DEC-0002](DEC-0002-five-bullet-hues.md) (v0.6.4), then [DEC-0003](DEC-0003-bullet-color-by-action.md) (v0.12.0) |
| Date | 2026-10-10, in the plan committed with v0.1.0 (`8bcae2a`) |
| Recorded | 2026-10-16, during onboarding ([TASK-0002](../production/tasks/TASK-0002-studio-onboarding.md)) |

**Question:** which colors exist in the game?

**Decision (as written):** `SPRINTS.md` §1, the Contrast pillar: "only two hues exist, red and
teal, and only on the Pilgrim, the boss, enemy bullets and explosion fringes. Everything else is
engraved monochrome." §3 added that bullets are "in the red family".

**Rationale:** contrast taken from Jason's two reference images; value first, so bullets read in
grayscale.

**Approval:** the plan of record from v0.1.0. No separate approval is recorded.

**Superseded:** for enemy bullets only. Jason asked for more hues in v0.6.4 (DEC-0002) and chose
"color by what to do" in v0.12.0 (DEC-0003). The rest still stands: color only on the Pilgrim,
the boss, enemy bullets and explosion fringes; teal is the Pilgrim's; everything else monochrome.

**Affected:** `SPRINTS.md` §1 and §3 (marked *Superseded* on 2026-10-16, the old wording kept).
