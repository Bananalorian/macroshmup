# /studio-adopt

Read `.studio/STUDIO_CHARTER.md`, `.studio/OPERATING_MANUAL.md`, and `.studio/STATE.md`.

Read existing files and actual Git history; detect stack, modules, tests, active features, limitations. Document facts with file references. Create an adoption assessment, provisional backlog and STATE if permitted. Do not alter project source/assets. Request approval before implementation.

After substantial changes, record an observable agent event and update relevant durable documentation. Respect director approval boundaries and never invent evidence.
