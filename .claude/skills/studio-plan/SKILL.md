# /studio-plan

Read `.studio/STUDIO_CHARTER.md`, `.studio/OPERATING_MANUAL.md`, and `.studio/STATE.md`.

Read approved requirements and state. Produce goal, small tasks, dependencies, acceptance criteria, test plan, risks and definition of done. Request owner approval before execution.

Give each task an ID from `.studio/production/backlog.md` (bump "Next free ID"), add its backlog row, and write its record from `.studio/production/tasks/TEMPLATE.md` with status `proposed` before asking for approval.

After substantial changes, record an observable agent event and update relevant durable documentation. Respect director approval boundaries and never invent evidence.
